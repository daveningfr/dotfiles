# Hyprland Rice

Personal Arch Linux desktop configuration built around Hyprland, Pywal, Kitty,
Waybar, SwayNC, Rofi, Neovim, and a small collection of shell utilities.

## Highlights

- Wallpaper-driven colors through Pywal
- Transparent Hyprland windows with blur and animated cursor
- Glass-styled Waybar, SwayNC, Rofi, and terminal
- Battery notifications with one-shot state handling
- Region screenshots with `Super+Shift+S`
- Compact floating windows with `Super+V`
- English/Pinyin input toggle with `Super+Space`
- Pywal themes for Bat and Discord

## Layout

Configuration files mirror their paths under `$HOME`. The scripts in
`.local/bin` are executable utilities used by the Hyprland configuration.

## Requirements

Arch Linux, Hyprland, Pywal, Kitty, Waybar, SwayNC, Rofi, Fcitx5, Bat, and
the Wayland tools `grim` and `slurp`.
